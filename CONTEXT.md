# DarshanFlow language

- **Monitored zone**: one of the four fixed operational areas: entry, primary queue, overflow queue, or darshan. The prototype does not create arbitrary live zones.
- **Display route**: an operator-configured arrow between monitored zones used to explain the temple's local movement layout. It is not an instruction to visitors and does not change the simulation model.
- **Simulation route**: the fixed, deterministic transfer assumptions used by the crowd model. It remains distinct from display routes until on-site validation is available.
- **Operations schematic**: the judge-facing spatial view of monitored zones, counts, and display routes. It is explicitly not a surveyed temple floor plan.
